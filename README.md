# Custom Chat Channels

**GM이 지정하는 채팅 채널(탭)과 참여자별 메시지 격리 기능을 제공하는 Foundry VTT V13용 모듈입니다.**

AI를 활용한 바이브 코딩으로 제작되었으며, D&D 5e와 Call of Cthulhu 7th Edition 환경에서 정상 구동을 확인했습니다.

<img width="908" height="570" alt="Custom Chat Channels" src="https://github.com/user-attachments/assets/6ec9479f-c564-4412-b00a-bda9f399c19d" />

제작자의 플레이 환경을 기준으로 테스트되었기 때문에, 다른 모듈과의 호환성은 충분히 검증되지 않았습니다.

**이 모듈은 `Custom Theatre System`의 종속 모듈입니다. `Custom Theatre System`이 설치되어 있지 않으면 사용할 수 없습니다.** https://github.com/yj9073773-jpg/custom-theatre-system/tree/main

## 기능 소개

- 채팅 탭 생성 및 참여자 지정
- `Custom Theatre System`과 연계한 스탠딩 채널 확장 기능 (최대 3개)
- 기타 모듈의 CSS 지정 기능

<img width="508" height="620" alt="Custom Chat Channels" src="https://github.com/user-attachments/assets/5e21ff4f-87a1-44ca-a1c5-081140bbf548" />

### 채팅 채널 관리

채팅 탭을 생성하거나 삭제할 수 있습니다. GM은 기본적으로 포함되며, 참여자를 지정할 수 있습니다.

메인 탭은 기본적으로 포함됩니다.

<img width="353" height="339" alt="채팅 채널 관리" src="https://github.com/user-attachments/assets/5cb318f5-322b-4c7d-a8f7-1aff261d71f4" />

### 스탠딩 채널 설정

생성한 채팅 탭을 스탠딩 채널에 최대 3개까지 등록할 수 있습니다.

최대 3개의 탭에서 진행되는 비주얼 노벨 연출을 채널 전환을 통해 확인할 수 있습니다.
